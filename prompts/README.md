# Everyday Prompts Library

Prompts are organized into folders by domain and sub-domain so it is easy to browse. Each prompt lives in its own file that includes metadata, usage notes, the prompt, and an example use case.

## Adding a New Prompt

1. Choose or create the correct domain or sub-domain folder.
2. Add a markdown file with frontmatter (`title`, `category`, `subcategory`, `description`, `llm_tools`, `inputs`).
3. Include sections for context, the prompt, examples, and any relevant tips.
4. Link to the new prompt from the nearest `README.md` so visitors can discover it quickly.
