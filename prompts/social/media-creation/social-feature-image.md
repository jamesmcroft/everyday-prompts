# Social Feature Image Prompt

Pair your social copy with an eye-catching visual. This prompt creates the instruction you can paste into an AI image generator so the style feels consistent with the post.

## Prompt

```text
I am writing a <PLATFORM> post providing insights into <TOPIC>. Provide an image prompt for an AI image generator. It must be in the format: (image we are prompting), (setting), (descriptive keyword), (camera type), (post processing techniques). No additional words or descriptions.

Context:
<Your opinions on the topic>
```

> [!NOTE]
> Keep the context short - just enough detail about the theme, tone, or outcomes you want the image to capture. The resulting output becomes the actual image generation prompt you can paste into your AI image generation tool of choice.
